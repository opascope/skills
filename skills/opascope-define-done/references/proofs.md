# Evidence for an objective

Choose a proof that measures the clause, not merely a convenient proxy.

| Shape | Evidence | Trap |
|---|---|---|
| Existence or count | Exact expected files or records are present | Empty or duplicate files can satisfy a count |
| Behavioral command | A command checks relevant behavior and exits 0 | A passing irrelevant test proves nothing |
| Independent review | A named reviewer checks a stated rubric and records a verdict | A worker's own PASS label is not independent |

Run available checks and record their actual result. Future checks must be
labeled as future, with inputs and expected output specified. A failed command
is not proof that the task is impossible; it may be the baseline showing work
is needed. Missing or unreadable inputs are errors, not a successful zero count.

For judgment, record reviewer identity or role, rubric, reviewed artifact
revision and findings. If no independent reviewer is available, report review
as pending. Do not turn a subjective clause into a file-existence test.

Example: a note migration requires the same set of content hashes before and
after, plus successful lookup of representative topics. A lower file count
does not prove duplicates were removed safely.
